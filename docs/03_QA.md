# 03 — Checklist de qualidade (QA)

Preencher: execução, data, versão, resultado, evidência e causa de falha. Não marcar OK sem executar.

## Build e boot
- [ ] SHA-256 e assinatura GPG da **ISO original** conferidos.
- [ ] A ISO customizada tem entrada de boot **Legacy BIOS** (`xorriso -report_el_torito`).
- [ ] `x86_64`, tamanho <8GB, meta <4GB, hash registrado.
- [ ] QEMU SeaBIOS: boota Live e reconhece mouse/teclado.
- [ ] QEMU: instala no disco qcow2 MBR, desanexa ISO e inicializa pelo HD virtual.
- [ ] No PC H55: pendrive em BIOS Legacy, Live Mint funcional, instalador completo e reboot direto pelo SATA.
- [ ] Regressão Ubiquity timezone: seleção manual de Brasilia ou região; instalar com e sem rede em VM, sem travar.

## Hardware e base
- [ ] `lspci -k`: Intel VGA reconhecida; kernel `i915` carregado.
- [ ] `glxinfo -B`: renderizador real; detectar llvmpipe e limitação OpenGL.
- [ ] Wi-Fi USB MT7601U (148f:7601), firmware e redes **2.4 GHz**; reconectar após reboot.
- [ ] Rede cabeada, áudio, vídeo 1360x768/60Hz, teclado ABNT2, USB 2.0.
- [ ] HDD e SSD SATA: instalação concluída e leitura/gravação; SMART se possível.
- [ ] Xfce e Mint Update iniciam sem erros e não requerem conexão para usar o desktop.

## Interface
- [ ] Whisker abre/pesquisa, favoritos e recentes.
- [ ] Toque isolado na tecla Super abre Whisker **sem bloquear** Super+setas.
- [ ] Super+←/→, Super+↑, Super+↓; Super+E/R/I, Ctrl+Shift+Esc.
- [ ] Plank bottom auto-hide e favoritos; painel superior com menu/relógio/rede/notificações.
- [ ] Thunar ações terminal, edição admin e extrair, confirmadas em arquivos **de teste**.
- [ ] Notificações canto superior direito e log/histórico real da versão XFCE.
- [ ] Tema WhiteSur opcional sem travamentos. Compositor on/off testado.
- [ ] Gestos 3/4 dedos: **N/A** sem touchpad de 3/4 pontos.

## Hub: cada botão
- [ ] Inventário/benchmark → HardInfo2 ou fallback hardinfo; relatório HTML testado se HardInfo2 existe.
- [ ] Comparação online HardInfo2 somente por ação explícita, respeitando privacidade.
- [ ] Histórico → HWall se instalado; fallback gera CSV/JSONL não vazios.
- [ ] Snapshot salva diretório distinto em `~/TestesPC/snapshots/` com hashes e sensores.
- [ ] Monitoramento em Tempo Real → SMC ou xfce4-taskmanager.
- [ ] GOverlay se instalado, caso contrário diálogo explicativo.
- [ ] Ativar/desativar MangoHud realmente persiste após logout/login; testar 2D OpenGL, 3D só se suportado.
- [ ] Synaptic instala/remove pacote **de teste**, confirmando comportamento correto.
- [ ] mintupdate abre e identifica atualizações.
- [ ] Waydroid/Cage: testar app Android x86 leve **somente se prerequisitos atendidos**; registrar N/A se não houver suporte GPU/binder.

## Performance
- [ ] RAM em repouso antes/depois, `free -h`, `ps aux --sort=-rss`, `swapon --show`, `zramctl`.
- [ ] Boot HDD vs SSD medido, multitarefa 5 abas, vídeo leve, documentos.
- [ ] Benchmarks CPU/memória/IO repetidos 3 vezes, sem comparar números desiguais.
- [ ] Comparação com Windows 10 apenas se existirem medições salvas no mesmo hardware; caso contrário escrever 'sem linha-base válida'.
- [ ] Reverter `configure-xfce`, zram, MangoHud, Whisker/Plank/gestos e tema com procedimentos do guia.

## Critérios de reprovação
- Falha de boot BIOS, travamento do instalador, tela preta, corrupção do filesystem, ausência de rede necessária ou interrupção da interface principal.
- Script do Hub sem ação/fallback compreensível.
- Snapshot sobrescreve relatório anterior; instala automaticamente firmware/driver experimental; telemetria não autorizada.
